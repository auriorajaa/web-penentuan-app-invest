# Smart Investment App Finder
*A simple decision-support website to help beginner investors choose the best investment applications.*

## 📌 Overview
Smart Investment App Finder is a user-friendly web platform designed to help individuals—especially beginner investors—make smarter and more informed investment decisions.  
The website offers educational content, comparison tools, and a decision-making system based on the **Simple Additive Weighting (SAW)** method.

Its main purpose is to guide users in finding the investment app that best matches their goals and risk profiles.

---

## 🎯 Purpose
This project aims to:

- Empower individuals with investment knowledge  
- Provide clear and simple guides  
- Help users compare investment applications based on structured criteria  
- Support decision-making using the SAW technique  
- Make investing easier and less confusing for beginners

## 🧠 How SAW Works
The **Simple Additive Weighting** technique evaluates each investment app by:
1. Scoring each criterion  
2. Normalizing the values  
3. Applying weights  
4. Summing the scores to generate a final ranking
